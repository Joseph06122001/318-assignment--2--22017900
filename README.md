# DCIT 318 Assignment 2

This repository contains three C# console applications demonstrating object-oriented programming:

- `InheritanceAndOverriding`: inheritance and method overriding with `Animal`, `Dog`, and `Cat`.
- `AbstractClassesAndMethods`: an abstract `Shape` class implemented by `Circle` and `Rectangle`.
- `Interfaces`: the `IMovable` interface implemented by `Car` and `Bicycle`.

## Run the applications

From the repository root, run any project with:

```bash
dotnet run --project InheritanceAndOverriding
dotnet run --project AbstractClassesAndMethods
dotnet run --project Interfaces
```

Build all projects with:

```bash
dotnet build Dcit318Assignment2.slnx
```
